# Bildreferenser
`approved/approved-board.png` är den utbyggda bild som användaren godkände. Numrerade utsnitt är beskärningar av samma bild och inte nya designförslag. De är lågupplösta presentationsreferenser, inte rena bilder/logotyper att lägga i applikationen.

`approved/original-three-options.png` ger den ursprungliga jämförelsen; välj C / alternativ 3, inte A eller B.

`current/` innehåller uppladdade originalbilder av nuvarande funktionalitet. Bild med träningsnotis har utelämnats eftersom samma UI finns i nästa bild. Statusfält/Safari är telefonens UI och ska inte byggas in i Smako.

Se `UI_SPEC.md` för korrigeringar av inkonsekventa siffersummor och reglagepositioner i den genererade designbilden.
