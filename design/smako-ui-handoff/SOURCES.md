# Underlag och källor
## Produktspecifikt
Användarens skärmbilder i `references/current/` och godkända design i `references/approved/` är källorna för visat UI. Användarens uttryckliga krav: alternativ 3; separat tillval av frukost och mellanmål; samma fullständiga inställningar som middag; motsvarande omdesign av näringsvärden, portionsvikt och fördelning.

Ingen extern sida används som belägg för Smakos aktuella stack, API eller faktiska funktioner. Repoinspektion krävs för dessa.

## Agentöverlämning
OpenAI:s dokumentation om tydliga uppdrag, kodkontext, bildreferenser och verifiering, kontrollerad 2026-10-14:
- https://developers.openai.com/codex/prompting/
- https://developers.openai.com/codex/guides/agents-md/

Instruktionen i detta paket ber agenten följa befintliga projektinstruktioner; den lägger inte till en root-AGENTS-fil som kan kollidera med användarens regler.

## Design och kod
Designtokens, ikonbanor, kodstruktur och testfall är framtagna för denna överlämning. Prototypens fixturevärden är illustrationer, inte källbelagda matpriser, täckningsdata eller rekommenderade näringsmål.
